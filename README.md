#  Аналіз кредитного портфеля та покриття NPL (2025–2026)

## Використані технології
* **Python 3.10+**
* **Streamlit** (UI та інтерактивні вкладки)
* **Plotly Express / Graph Objects** (візуалізація динаміки)
* **Pandas** (чистка та агрегація даних НБУ)
